# School Admission System

Online admission system for a school where seats are given on a first-come, first-served basis.
Each class/shift has a fixed number of seats. Applying places a temporary hold on a seat; the
admission is confirmed once the fee is paid before the hold expires.

## Stack

- Backend: ASP.NET Core (C#), PostgreSQL
- Frontend: React + Vite
- Everything runs with Docker Compose

## Project structure

```
backend/    ASP.NET Core Web API
frontend/   React (Vite) client
docker-compose.yml
```

## Running

> Work in progress. Full instructions will be added as services are completed.
